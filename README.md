# Manish Kumar — Portfolio

A simple single-page developer portfolio built with plain HTML, CSS and JavaScript.

## Includes

- Responsive design
- About section
- Technical skills
- Featured Projects showcase
- Experience timeline
- Direct email and phone contact
- GitHub Pages compatible
- No backend
- No contact-form service

## Before publishing

Replace these placeholders in `index.html`:

- `your-email@example.com`
- `+91 XXXXX XXXXX`
- `+910000000000`
- Project `https://example.com` links

You can also replace the project titles, descriptions and technologies with your actual projects.

## GitHub Pages

Upload `index.html`, `styles.css`, `script.js` and the `assets` folder to your GitHub repository.

Then enable:

**Settings → Pages → Deploy from a branch → main → / (root)**
